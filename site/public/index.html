exit arc 👋

Arc stops working on 22 December 2026. Arc's sunset dates

exit-arc takes your sidebar with you: every space, its pinned tabs and folders, your Favourites and your list of extensions. It can save them as plain files, or set them up in another browser.

Move your Arc life to

  • Firefox
  • Zen
  • Chrome
  • Plain Python, no dependencies
  • Runs on your Mac
  • Only reads Arc's files
  • Sends nothing anywhere unless you ask it to look up extensions

How to run it

Install it with Homebrew:

brew install meelijane/tap/exit-arc

Then run it in Terminal:

exit-arc

Without Homebrew: download exit-arc.pyz from the latest release and run python3 exit-arc.pyz.

It asks a few questions, then does the rest:

  1. Which Arc profile?

    Only asked if you have more than one. The default is all of them.

  2. Here's what it found

    Your Favourites, and each space with its pinned tabs and folders.

  3. Where are you moving to?

    Firefox, Zen, Chrome, or no browser: just save the files.

  4. What should it set up there?

    It lists only what that browser supports, including making it your default browser. Press Enter for all of them, or type the numbers you want.

  5. Keep your bookmarks or replace them?

    Only asked if the browser already has bookmarks of yours. The default is to keep them and import the bookmarks file yourself; it shows you how.

  6. Remove Arc when it's done?

    Only asked if Arc is installed. The default is no.

  7. Where should the files go?

    The default is ~/Desktop/arc-export.

  8. Go ahead?

    Nothing changes until you say yes. If the browser is open, it asks before quitting it.

You'll need

  • macOS with Arc's data still on disk (~/Library/Application Support/Arc)
  • Python 3.8 or newer. Macs with Homebrew already have it; otherwise macOS offers to install it the first time you run python3.
  • The browser you're moving into, if any. Open it once and quit it first, so it has a profile.

You always get these files

  • arc-sidebar.md: a readable page with a heading per space, nested folders, Favourites and your extensions
  • arc-tabs.csv: one row per tab
  • arc-bookmarks.html: a standard bookmarks file any browser can import
  • arc-export.json: everything, for other tools

What each browser gets

Good to know

  • Adding bookmarks to Firefox or Zen replaces every bookmark in the profile. If you already have bookmarks there, exit-arc asks first and keeps them unless you choose to replace them.
  • Everything it changes in the browser is backed up first, next to your files.
  • Chrome bookmarks are experimental. If they don't appear, import arc-bookmarks.html in Chrome by hand.
  • Zen spaces are tested on Zen 1.24. Zen doesn't document the file they live in, so a future Zen version may change the format.
  • Extensions: only extension names are sent to addons.mozilla.org, and only when you choose Extensions. Nothing is installed without your OK.
  • Removing Arc is optional and recoverable. You choose the app only, or the app and its data. It runs only after everything else has worked, moves things to the Trash, and asks once more first. Arc's history, passwords and cookies aren't moved to your new browser, so export them from Arc first if you want them.

What stays behind

  • History
  • Passwords
  • Cookies and logins
  • Extension data and settings
  • Boosts
  • Easels
  • Notes
  • Little Arc
  • Site permissions

For history and passwords, use the browser's own importer or a password manager.
