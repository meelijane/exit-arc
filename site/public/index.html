exit arc

Arc stops working on 22 December 2026. Arc's sunset dates

exit-arc takes your sidebar with you: every space, its pinned tabs and folders, your Favourites and your list of extensions. It can save them as plain files, or set them up in Firefox, Zen or Chrome.

  • Plain Python, no dependencies
  • Runs on your Mac
  • Only reads Arc's files
  • Sends nothing anywhere unless you ask it to look up extensions

What each browser gets

Every step is opt-in. --all runs every step the browser supports.

Good to know

  • Bookmarks on Firefox and Zen replace every bookmark in the profile. It's meant for a fresh browser. If the profile has bookmarks of your own, exit-arc stops before changing anything, unless you add --replace-existing.
  • Every file it changes is backed up first.
  • Chrome bookmarks are experimental. If they don't appear, import arc-bookmarks.html in Chrome by hand.
  • Zen spaces are tested on Zen 1.24. Zen doesn't document the file they live in, so a future Zen version may change the format.
  • Extensions: only extension names are sent to addons.mozilla.org, and only when you use --extensions. Nothing is installed silently.
  • --dry-run shows what would happen and changes nothing.

What stays behind

  • History
  • Passwords
  • Cookies and logins
  • Extension data and settings
  • Boosts
  • Easels
  • Notes
  • Little Arc
  • Site permissions

For history and passwords, use the browser's own importer or a password manager.
